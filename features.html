Module 01

Ingestion & High-Speed RAW Decoding

Mounts original camera memory cards or hard disks in strictly Read-Only mode. Utilizes custom LibRaw C-bindings to achieve sub-15ms extraction of camera-generated EXIF preview buffers. Full-fidelity proxies are generated asynchronously in .photoflow_cache/ for 100% pixel loupe zoom.

  • ✓
    Universal Format Support:

    Sony (.ARW, .SR2), Canon (.CR2, .CR3), Nikon (.NEF, .NRW), Fujifilm (.RAF), Adobe (.DNG), and standard JPG/PNG/TIFF.

  • ✓
    Two-Tier Fast Preview Cache:

    Tier 1 allows smooth 60fps scrolling through 10,000 photos instantly. Tier 2 loads linear proxies for focus confirmation.

Module 02 & 03

AI Culling & Duplicate Clustering Engine

Evaluates focus crispness via modified Laplacian Variance and facial pupil high-frequency gradients. Simultaneously computes Eye Aspect Ratio (EAR) across all facial landmarks to catch blinks.

1. Sharpness Laplacian Variance:

σ²(∇² I) = Var( ΔI ) [Face-weighted Edge High-Pass]

2. Eye Aspect Ratio (EAR) Formula:

EAR = ( ||p₂ - p₆|| + ||p₃ - p₅|| ) / ( 2 · ||p₁ - p₄|| )

If EAR < 0.20 during flash bursts, the shot is automatically tagged as a blink and downgraded to REVIEW or REJECT.

Module 05

Skin-Tone Science & the +5% Vibrance Boost

Why does foreign software burn Indian bridal portraits? Standard saturation scales all pixels equally. Ai PhotoFlow translates RGB into YCrCb space, isolating human skin pixels so facial tones stay creamy while embroidery pops.

1. YCrCb Skin Chrominance Gate:

Skin_Mask = (Cr ∈ [133, 173]) ∩ (Cb ∈ [77, 127])

2. Universal +5% Vibrance Equation:

Vibrance_applied = clip( Vibrance_calc + 5.0, 5.0, 35.0 )

The algorithm selectively boosts undersaturated hues (bridal flowers, stage decor, gold zardozi) while skipping pixels flagged in the skin mask.

Module 07 & 08

Hardware Fingerprint Cryptographic Keys

To ensure zero software piracy while permitting 100% offline usage in remote banquet halls without Wi-Fi, Ai PhotoFlow binds each seat to three unalterable hardware primitives:

  • 1. Motherboard UUID: ioreg on macOS / wmic csproduct get uuid on Windows
  • 2. CPU ID: Primary processor silicon architecture & serial register
  • 3. MAC Address: Primary physical network adapter hash
Signature = HMAC_SHA256( Machine_UUID + CPU_ID + Expiry, Salt_32B )

Licenses follow standard enterprise syntax: FLOW-XXXX-XXXX-XXXX-XXXX. Includes monotonic anti-clock-rollback protection to prevent system clock tampering.
